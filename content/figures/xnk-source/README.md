# XNK figure data (source copy)

Unedited copies of `figure.min.json` (muscle map) and `rig.min.json` (exercise rig patterns) from the XNK repo `xnkzzxd/xnk`, folder `figure/`, last changed in XNK commit `6dc57b3` (read 2026-11-18). Both are build output of XNK's `tools/build-figure.js` and `tools/build-rig.js`: do not edit by hand; copy again from XNK when it changes.
Credits and the MIT licence of the muscle shapes (react-muscle-highlighter) are in `CREDITS.md` and `LICENSE-react-muscle-highlighter.txt` and must ship with the app.
Joint angles in the rig come only from XNK `docs/program/Gerak.md`.

`docs/Gerak.md` and `docs/Otot.md` are unedited copies of XNK `docs/program/Gerak.md` (joint angles with sources for the rig patterns) and `docs/program/Otot.md` (main and helper muscles from EMG studies), copied from the local XNK checkout at commit 8001bd3 on 2026-11-18 so sessions do not need access to the XNK repo.
